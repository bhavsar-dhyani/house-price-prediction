# House Price Prediction

A machine learning project that predicts house prices using regression algorithms on the USA Housing dataset.

## About the Project
This project uses features such as average area income, house age, number of rooms, number of bedrooms and area population to predict the price of a house.

## Tools and Libraries
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Files
- `House Price Prediction using Regression Algorithms (2).ipynb`: the full notebook with analysis and models
- `USA_Housing.csv`: the dataset

## How to Run
1. Download or clone this repository
2. Open the notebook in Jupyter Notebook or VS Code
3. Run all the cells from top to bottom
